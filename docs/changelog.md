# 更新日志

命令行（npm 包 `yunbox`）和 macOS 客户端共用一个版本号。新版本的说明也会显示在客户端的更新提示里。[English](./en/changelog)

## 未发布

### 新增

- macOS 客户端支持自动更新：每天在后台检查一次，也可以从「云匣 YunBox → 检查更新…」手动检查；更新包和更新说明都经过签名校验。
- macOS 客户端支持简体中文和英文界面，可以在「设置 → 语言」里切换，也可以跟随系统。
- 新增更新日志页面，客户端的「帮助」菜单和「设置 → 软件更新」可以直接打开。
- 禁推时段：用 `yunbox freeze` 设置每周固定的禁止推送时段（例如工作时间），pre-push 在时段内拦截推送；规则可以只对本仓库、整个团队或本机所有仓库生效。
- `yunbox freeze off` 临时关闭禁推时段，可以指定时长或截止时间，到点自动恢复。
- macOS 客户端在菜单栏显示当前仓库能否推送，可以查看今天和未来 7 天的禁推时段、一键套用预设或临时关闭。
- macOS 客户端的 COS 面板可以复制一段给 AI 编程助手的接入说明。
- `git yunbox types` 按素材类型管理 LFS 规则：查看每个类型是否走 LFS、有多少文件，列出作为普通文件提交的素材（包括 Linux 上大小写不同的扩展名，例如 `HERO.PNG`）；`add` 追加类型，`--renormalize` 把已提交的文件从下一次提交起改存为 LFS；`remove` 只删除 YunBox 生成的规则。`--json` 供图形界面读取。
- 素材类型可以用预置组合快速选择：`game`、`design`、`media`、`all`，`git yunbox init --types` 也接受。
- 文档新增「从 GitHub LFS 迁移」指南：把 GitHub LFS 或其他 LFS 服务里的全部历史素材搬到自己的 COS，包含验证、协作者切换和回滚方法。

### 修复

- `git yunbox init` 不再给已经有文件作为普通文件提交过的类型添加 LFS 规则，避免这些文件显示为已修改、在新的 clone 里报错；会列出这些文件并给出改用 LFS 的命令。

## 0.1.4 - 2026-10-19

### 新增

- 推送确认里可以预览改动的文件，文本文件显示逐行差异。
- macOS 客户端可以对比所选文件推送前后的版本，文本差异可以在统一视图和左右分栏之间切换。

## 0.1.3 - 2026-10-19

### 新增

- 推送超出预算时，逐个列出文件并请你确认。
- 文档改为 VitePress 网站，提供下载入口。

### 变更

- 团队共享的配置移到 `.yunbox/config`；旧的 `.yunboxconfig` 仍然可以读取，`yunbox doctor` 会给出迁移命令。

## 0.1.2 - 2026-10-19

### 新增

- `yunbox subaccount` 一条命令创建只有所需权限的子账号长期密钥，并保存到本机。

## 0.1.1 - 2026-10-19

### 修复

- `git yunbox init` 在不需要提问时会正常退出，不再卡住终端。
- Windows 上 git-lfs 能正常启动传输代理，`yunbox hook install` 也能正常工作。

## 0.1.0 - 2026-10-19

### 新增

- 第一个公开版本：Git LFS 素材直接上传到你自己的腾讯云 COS，不需要服务端。
- `git yunbox init`、`doctor`、`status`、`login`、`policy` 等命令；macOS 上密钥保存在钥匙串。
- 推送前检查 Git 和 LFS 的上传体积。
- macOS 客户端：检查推送体积，查看 COS 直连状态并在窗口里完成接入。
